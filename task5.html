Responsive CSS Cheat Sheet

Filters

CSS filters like grayscale(), sepia(), or blur() modify how images are displayed. Example: filter: grayscale(100%);

Media Queries

Media queries adjust layout based on screen size. Example: @media (max-width: 600px) { ... }

Responsive Design

Uses flexible layouts and media queries to make websites look good on all devices.

Typography

Text that scales automatically using clamp() and relative units like rem or vw. Example: font-size: clamp(1rem, 2vw, 2rem);
